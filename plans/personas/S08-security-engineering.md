# S08 — Security Engineering Squad

- **Division:** Software Engineering (ENG)
- **Mission:** Secure the products, data, and supply chain end to end
- **Headcount:** 6 personas
- **Reports to:** Chief Information Security Officer (CISO)

## 1. Purpose

The Security Engineering Squad protects the company's products, data, and software supply chain across their whole lifecycle. It embeds security into how software is designed, built, and shipped, and it provides the guardrails, detection, and response the rest of engineering relies on. The squad exists to make the secure path the easy path, reduce risk before it reaches production, and keep trust with customers and regulators.

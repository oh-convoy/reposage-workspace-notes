# Corporation — Squad Catalogue

The organizational blueprint for a software-and-media corporation spanning
**software development, artificial intelligence, digital marketing, social media,
multimedia & design, and video/audio production**, plus the corporate shared
services such a company requires.

This document is the **source of truth for the squad numbering**. Every persona
document under `../personas/` expands exactly one squad from this catalogue.

## How to read this

- **Divisions** (Table 1) group squads by discipline.
- **Squads** (Table 2) are the numbered units. Each has an ID `S##`, a mission,
  and a target headcount.
- **Table 3** gives the persona roster size per squad.
- Each squad is expanded in `../personas/S##-<slug>.md`.

## Table 5 — Diversity standard (applies to every squad)

Each squad's personas are drawn to satisfy:

| Dimension | Standard |
|---|---|
| Gender | Mixed within each squad; no squad is single-gender |
| Geography | At least 3 countries per squad; all continents represented company-wide |
| Ethnicity / heritage | Mixed within each squad |
| Names | Real, human, culture-appropriate names (no placeholders) |
| Experience | A spread from early-career to principal-level |

See each persona document's diversity table for the actual composition.
